# Recursos visuales

Identidad Leytech (símbolo L, icono y composición) creada para este proyecto. Iconografía: Lucide, licencia ISC, distribuida como dependencia.

Tipografía Manrope, obtenida del servicio Google Fonts, servida localmente. Licencia SIL Open Font License en `public/fonts/OFL.txt`. Fuente de licencia: <https://github.com/google/fonts/tree/main/ofl/manrope>.

Fotografías ilustrativas de Unsplash descargadas a `public/images`. No se tomaron recursos de las tiendas de benchmarking. Son material de demostración: no acreditan marcas, modelos, características o disponibilidad comercial de Leytech. Reemplazar con fotografías autorizadas del catálogo real.

Los identificadores y las URL de origen se conservan en `scripts/assets.mjs`. Imagen alternativa de redes: <https://images.unsplash.com/photo-1558494949-ef010cbdcc31>. Licencia: <https://unsplash.com/license>. El script no debe volver a ejecutarse para cambiar el catálogo comercial sin revisar sus imágenes.

Las fotos con marcas visibles no implican una relación comercial con esas marcas. Los ejemplos se nombran de forma genérica y la ficha muestra que son ilustraciones.
